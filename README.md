# 🚀 MacroMate

A full-stack fitness web application for **macro tracking, calorie planning, and progress monitoring**.

---

## 🌐 Live Demo
🔗 https://macromate-ai.onrender.com

---

## 📌 Features

- 🔐 **User Authentication (OTP-based)**
- 📊 **Macro Calculator (Protein, Carbs, Fats)**
- 📈 **Progress Tracking System**
- 🧠 **Calorie Management (Cut/Bulk/Maintain)**
- 📬 **Email OTP Verification**
- ⚡ Fast and responsive UI
